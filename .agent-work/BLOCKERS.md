## Human-only actions likely required

- Connect/configure a Devnet wallet in the browser.
- Obtain Devnet SOL from an official faucet if needed.
- Provide an AI provider API key locally if live AI generation is desired.
- Approve wallet signatures for real Devnet transactions.
- Approve any external deployment or GitHub push.

Never ask the user to paste a seed phrase or private key into chat, prompts, source code, or environment variables.
